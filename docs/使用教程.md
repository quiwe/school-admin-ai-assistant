# 高校行政 AI 回复助手 - 使用教程

版本：0.7.0

开发者：maoqiu

## 一、软件简介

高校行政 AI 回复助手是一款面向高校行政老师的桌面端软件，用于辅助回复学生日常咨询。

它可以根据老师上传的知识库文件和 FAQ 常见问答，生成规范、温和、可复制的回复草稿。老师可以在回复工作台中手动生成回复，也可以配置学生网页端、QQ Bot 或企业微信机器人，让学生通过网页、QQ 或企业微信提交问题。

本软件适合以下场景：

- 教务、学工、研究生管理、论文答辩、学籍事务等高频咨询。
- 学生反复询问流程、系统操作、材料提交、时间节点等问题。
- 老师希望统一回复口径，减少重复打字。
- 学校或学院希望沉淀 FAQ 和办事资料。

重要提醒：

> 所有 AI 回复都应视为草稿。涉及成绩、处分、奖助学金、学籍状态、个人隐私、投诉申诉、心理危机等敏感事项时，请人工核实后再回复。

## 二、首次使用：配置 AI 模型

首次打开软件后，需要先配置一个可用的大模型，否则无法生成回复。

以下以 DeepSeek 为例。

### 第一步：获取 API Key

1. 打开 DeepSeek 开放平台：https://platform.deepseek.com/
2. 注册并登录账号。
3. 进入 API Keys 页面。
4. 点击创建 API Key。
5. 复制生成的 Key，通常以 sk- 开头。

注意：

- API Key 只显示一次，请立即保存。
- 不要把 API Key 发到群里，也不要写入公开文档。

### 第二步：在软件中保存模型配置

1. 打开软件，点击左侧菜单的系统设置。
2. 在常用大模型 API 设置中，选择当前启用的 Provider，例如 DeepSeek。
3. 填写 API Key。
4. Base URL 默认通常不需要修改。
5. 点击识别模型。
6. 在模型下拉框中选择要使用的模型。
7. 点击保存模型配置。
8. 点击测试模型，确认能正常返回结果。

推荐先选择速度快、费用低的模型进行日常咨询回复。

### 第三步：测试回复

1. 点击左侧菜单的回复工作台。
2. 输入一个测试问题，例如：老师，我论文系统上传后一直显示待审核怎么办？
3. 点击生成回复。
4. 如果右侧出现回复内容，说明 AI 模型配置成功。

## 三、知识库管理

知识库是 AI 回复时参考的资料。上传的资料越完整，回复越准确。

支持的文件格式：

- PDF
- Word：doc、docx
- PPT：ppt、pptx
- Excel：xls、xlsx
- TXT

上传步骤：

1. 点击左侧菜单的知识库管理。
2. 点击选择文件。
3. 选择文件分类，例如毕业论文、学籍管理、系统操作、其他。
4. 点击保存文件到知识库。
5. 等待系统解析文件并建立索引。

建议上传的资料：

- 学校或学院办事流程。
- 常见问题汇总。
- 论文、答辩、学位系统操作说明。
- 学籍、培养、奖助、就业等相关通知。
- 老师平时整理的标准答复。

Excel 导入 FAQ：

如果 Excel 第一行包含问题、答案、分类等列，可以在上传时选择 Excel 导入 FAQ。系统会把表格内容导入 FAQ 管理列表，并跳过相似重复项。

## 四、FAQ 管理

FAQ 是常见问题和标准答案，比普通知识库文件更适合稳定、高频的问题。

新增 FAQ：

1. 点击左侧菜单的 FAQ 管理。
2. 在常见问题中填写学生可能会问的问题。
3. 在标准答案中填写老师认可的回复。
4. 选择分类。
5. 勾选允许自动作为依据。
6. 点击新增 FAQ。

管理 FAQ：

- 可以搜索关键词。
- 可以编辑问题、答案、分类。
- 可以删除不再使用的 FAQ。
- 可以从 Excel 批量导入。
- 可以导出 FAQ 备份。

建议：

- 把最稳定、最常问的问题优先整理为 FAQ。
- 回复工作台中生成得比较好的回复，可以保存为 FAQ。
- 如果政策变更，请及时更新 FAQ，避免学生看到旧口径。

## 五、回复工作台

回复工作台适合老师手动处理学生咨询。

基本流程：

1. 从微信、QQ、邮件或其他渠道复制学生问题。
2. 粘贴到学生问题输入框。
3. 点击生成回复。
4. 查看问题分类、置信度、检索依据和 AI 回复。
5. 老师检查并修改回复。
6. 点击复制回复，再发给学生。

回复生成后可以继续调整：

- 更正式：让语气更规范。
- 更简短：压缩文字长度。
- 更温和：让语气更亲切。
- 重新生成：不满意时重新生成一版。

页面会显示本次模型用量，包括 token、缓存命中率和估算费用。费用仅供参考，实际费用以模型平台账单为准。

## 六、学生网页端

学生网页端适合同一局域网内的学生自助咨询。

使用方式：

1. 老师打开桌面端软件。
2. 软件顶部会显示网页端地址。
3. 点击打开网页端，可以复制完整地址。
4. 老师把完整地址发给同一局域网内的学生。
5. 学生打开地址后即可输入问题。

注意：

- 老师电脑和学生设备需要在同一局域网。
- 老师电脑防火墙需要允许当前端口访问。
- 网页端地址带访问码，不要公开到无关群组或公网。
- 远程学生只能访问学生咨询页面，知识库、FAQ、历史记录、设置等管理页面仍限制为老师电脑本机使用。

局域网检查方法：

1. 老师电脑先保持软件打开。
2. 在软件顶部复制网页端地址。
3. 用同一 Wi-Fi 或同一有线局域网内的另一台电脑或手机打开该地址。
4. 页面能显示学生咨询助手，并且可以正常发送测试问题，说明局域网访问可用。
5. 如果打不开，请检查老师电脑和学生设备是否在同一网络，并允许 Windows 防火墙或 macOS 防火墙放行本软件当前端口。

补充说明：

- 地址中的 `192.168.x.x` 或 `10.x.x.x` 是老师电脑的局域网 IP。
- 地址中的访问码只用于学生咨询页，不要删除。
- 学生链接不会开放管理功能。

## 七、聊天机器人总览

当前版本支持两类聊天机器人：

- 企业微信 AI 机器人。
- QQ Bot。

机器人会复用同一套知识库、FAQ、敏感问题检测和大模型配置。也就是说，先把知识库、FAQ 和 AI 模型配置好，再启用机器人。

机器人适合以下场景：

- 学生在企业微信或 QQ 中直接向机器人提问。
- 群聊中学生 @ 机器人提问。
- 老师希望自动收集历史咨询记录。

重要提醒：

- 机器人自动回复更接近实时发送，请务必先上传可靠知识库和 FAQ。
- 敏感问题会按系统规则提示人工核实。
- 如果没有找到可靠依据，机器人会提示补充信息或人工核实。
- 机器人配置后，软件或后台服务需要保持运行。

## 八、企业微信机器人配置

企业微信使用 WebSocket 长连接，无需公网 IP。

### 第一步：在企业微信后台创建 AI 机器人

1. 登录企业微信管理后台。
2. 进入 AI 机器人相关管理页面。
3. 创建一个新的 AI 机器人。
4. 设置机器人名称、头像和简介。
5. 复制 Bot ID。
6. 复制 Secret。

建议机器人简介填写：

> 我可以根据学校知识库和常见问答，回答教务、学籍、论文、办事流程、材料提交、系统使用等常见咨询，并给出清晰规范的回复建议。涉及成绩、处分、奖助学金、个人隐私等敏感事项，请联系老师人工核实。

### 第二步：在软件中保存企业微信配置

1. 打开软件，点击系统设置。
2. 找到聊天机器人区域。
3. 接入渠道选择企业微信。
4. 填写 Bot ID。
5. 填写 Secret。
6. 根据需要填写允许名单。
7. 勾选启用企业微信。
8. 点击保存企业微信配置。

保存成功后，右侧状态应显示机器人运行中。

允许名单说明：

- 留空表示允许所有企业微信用户使用。
- 如果填写，只允许名单中的企业微信 UserID 使用。
- 多个 UserID 可以用空格、逗号或换行分隔。

### 第三步：测试企业微信机器人

单聊测试：

1. 在企业微信中找到该机器人。
2. 发送：你好。
3. 再发送：怎么提交论文。
4. 如果机器人返回回复，并且历史记录中出现对应问题，说明单聊成功。

群聊测试：

1. 把企业微信机器人加入群聊。
2. 在群里 @机器人，并输入问题，例如：@机器人 怎么提交论文。
3. 如果机器人在群里回复，说明群聊连接成功。

排查方法：

- 如果状态显示机器人未运行，请重新检查 Bot ID 和 Secret。
- 如果保存后提示 invalid bot_id or secret，说明 Bot ID 或 Secret 不匹配，请回企业微信后台重新复制。
- 如果单聊正常但群聊不回复，请确认机器人已被加入群聊，并且消息是 @ 机器人发送的。

## 九、QQ Bot 配置

QQ Bot 适合 QQ 私聊和 QQ 群聊 @ 自动回复。

### 第一步：在 QQ 机器人开放平台创建机器人

1. 打开 QQ 机器人开放平台。
2. 创建或选择一个机器人应用。
3. 获取 AppID。
4. 获取 AppSecret。
5. 根据平台要求完成机器人发布、权限或测试配置。

注意：

- AppID 和 AppSecret 必须来自同一个机器人应用。
- AppSecret 不要公开。
- 如果还在测试阶段，可以按平台要求使用沙箱环境。

### 第二步：在软件中保存 QQ Bot 配置

1. 打开软件，点击系统设置。
2. 找到聊天机器人区域。
3. 接入渠道选择 QQ Bot。
4. 填写 AppID。
5. 填写 AppSecret。
6. 如需测试沙箱，勾选使用沙箱环境。
7. 根据需要填写 Owner OpenID 或允许名单。
8. 勾选启用 QQ Bot。
9. 点击保存 QQ 配置。

保存成功后，右侧状态应显示机器人运行中。

Owner OpenID 和允许名单说明：

- Owner OpenID：只允许这个 QQ 用户使用，也可同时允许名单中的用户使用。
- 允许名单：多个 OpenID 可以用空格、逗号或换行分隔。
- Owner 和允许名单都留空时，QQ 私聊会绑定首次发消息的用户。
- QQ 群聊 @ 场景下，如果没有设置 Owner 或允许名单，群成员 @ 机器人也可以触发回复。

### 第三步：测试 QQ Bot

私聊测试：

1. 在 QQ 中找到机器人。
2. 给机器人发送：你好。
3. 再发送：怎么提交论文。
4. 如果机器人自动回复，并且历史记录中出现对应问题，说明私聊成功。

群聊测试：

1. 把 QQ Bot 拉入 QQ 群。
2. 在群里 @机器人，并输入问题，例如：@机器人 怎么提交论文。
3. 如果机器人在群里回复，说明群聊 @ 成功。

注意：

- QQ 群聊需要 @ 机器人，普通群消息不会触发自动回复。
- 群聊被动回复有时间和频率限制，短时间内不要反复刷同一个问题。
- 如果群聊不回复，请确认机器人已在 QQ 平台开通群聊相关能力，并且当前群允许机器人发言。

## 十、开机自启动、macOS 与 Android APK

### 开机自启动

安装版默认开机后自动启动。

关闭方式：

1. 打开软件，进入系统设置。
2. 找到开机自启动。
3. 取消勾选开机后自动启动。
4. 点击保存自启动设置。

重新开启时，勾选后再次保存即可。

说明：

- Windows 版本会使用当前用户的系统启动项。
- macOS 版本会使用当前用户的 LaunchAgent。
- 开机自启动只在 Windows 和 macOS 安装版中生效。

### macOS 版本

macOS DMG 版本功能与 Windows 桌面版保持一致，包括回复工作台、知识库、FAQ、历史记录、系统设置、学生网页端和聊天机器人配置。

首次打开如果被系统拦截，可在系统设置中允许打开。macOS 安装版首次运行后会自动创建开机自启动项，也可以在系统设置中关闭。

### Android APK

Android APK 通过局域网连接老师电脑上的桌面端服务，使用同一套知识库、FAQ、历史记录和模型配置。

使用方式：

1. 老师电脑先打开桌面端软件。
2. 在桌面端进入系统设置。
3. 找到移动端 / APK 连接。
4. 复制完整管理地址。
5. 在 Android 手机上安装并打开 APK。
6. 首次打开时粘贴完整管理地址。
7. 保存后即可进入移动端界面。

注意：

- APK 需要和老师电脑处在同一局域网。
- 完整管理地址带管理访问码，只发给需要管理权限的老师本人。
- 学生仍应使用顶部网页端地址，不要使用 APK 管理地址。

## 十一、数据备份与恢复

系统设置中提供数据备份与恢复。

备份包含：

- FAQ。
- 知识库解析文本。
- 历史记录。
- 非密钥设置。

备份不包含：

- API Key。
- AppSecret。
- 企业微信 Secret。

导出备份：

1. 进入系统设置。
2. 找到数据备份与恢复。
3. 点击导出备份。
4. 保存生成的 JSON 文件。

导入备份：

1. 进入系统设置。
2. 选择备份 JSON 文件。
3. 点击导入备份。
4. 系统会追加导入数据，并跳过相似 FAQ。

## 十三、常见问题

Q：生成回复时提示大模型调用失败？

A：进入系统设置，检查 API Key、Base URL 和模型名称是否正确。建议点击测试模型。

Q：AI 回复不准确？

A：优先上传更完整的知识库文件，并把高频问题整理为 FAQ。AI 只能根据已有资料和 FAQ 生成回复。

Q：为什么涉及成绩、处分、奖助学金的问题回复很保守？

A：这是安全规则。此类问题涉及个人情况或正式结论，系统会建议人工核实。

Q：企业微信机器人显示未运行？

A：通常是 Bot ID 或 Secret 不正确，或者网络无法连接企业微信 WebSocket。请重新复制配置并保存。

Q：QQ Bot 显示未运行？

A：通常是 AppID、AppSecret 或沙箱环境选择不正确。请确认配置来自同一个机器人应用。

Q：机器人私聊能回复，群聊不回复？

A：请确认机器人已经被拉入群聊，并且群里是 @机器人 后提问。QQ 群聊普通消息不会触发回复。

Q：历史记录没有新消息？

A：说明问题没有进入本地回复链路。请检查机器人运行状态、平台配置、允许名单和群聊 @ 是否正确。

Q：启动后窗口打不开？

A：检查杀毒软件或系统防火墙是否拦截。如果提示本地服务启动失败，请把 logs/startup.log 发给开发者排查。

## 十四、使用建议

- 先配置模型，再上传知识库，最后配置机器人。
- 先用回复工作台测试几条常见问题。
- 再测试学生网页端或聊天机器人。
- 对自动回复场景，建议先小范围试运行。
- 定期导出数据备份。
- 政策更新后，及时更新知识库和 FAQ。
- 不要把 API Key、AppSecret、Secret 发到群里。
